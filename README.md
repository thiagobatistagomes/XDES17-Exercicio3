# XDES17-Exercicio3

Exercício de Tilemap: cenário com Background e Foreground, colisões, animações Idle/Running, movimentação com PlayerInput, câmera Cinemachine e desafio de pulo duplo.

## Abrir e executar

1. Baixe o repositório ou clone-o.
2. No Unity Hub, adicione a pasta do projeto e abra com **Unity 6000.5.8f1**.
3. Aguarde o Unity importar os assets e restaurar os pacotes.
4. Abra `Assets/Scenes/Exercise3.unity` e pressione **Play**.
5. Clique na janela **Game** para receber os comandos. Use proporção **16:9**.

## Controles

- **A/D** ou setas esquerda/direita: movimentação.
- **Espaço**: pulo; pressione novamente no ar para pulo duplo.
- **Gamepad**: analógico esquerdo para movimentação e botão sul (A/Cross) para pular.

## Organização

- `Assets/Tiles`: tiles e paletas Background/Foreground.
- `Assets/Animations/Player`: animações e controlador do personagem.
- `Assets/Scripts/Player.cs`: movimentação, animação e pulos.
- `Assets/Prefabs/Player.prefab`: personagem configurado.
- `Assets/Art`: sprites e áudio fornecidos.
- `Assets/Scenes/Exercise3.unity`: cena pronta para executar.
